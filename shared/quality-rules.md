# Quality Rules — Shared Across All Skills

## HOOK RULE — Non-Negotiable
Every piece of content starts with the hook. No exceptions.
Before writing body copy, emails, landing pages, or ads:
→ Generate 5 hook options first
→ User picks one
→ Everything else is built around that hook

Hook formats that work:
- Pain: "Ако правиш X, значи имаш Y проблем"
- Curiosity: "[Number] причини защо [painful result] — въпреки [effort]"
- Story: "Тя правеше [X]. После направи [Y]. Ето разликата."
- Contrarian: "Всички казват [advice]. Ето защо не работи."
- Call-out: "Това е за [specific person] с [specific problem]."

## QUALITY GATES — Never Ship Without These
❌ Never: Starts with "Здравейте" or "Днес искам да споделя"
❌ Never: Features instead of outcomes
❌ Never: More than ONE CTA per piece
❌ Never: Vague language ("много", "значително", "успешен")
❌ Never: Sounds like AI wrote it

✅ Always: Uses client's exact words from Brand DNA
✅ Always: Specific number, name, or timeframe
✅ Always: Reader feels seen before you ask anything
✅ Always: One clear, low-friction next step

## BELIEF-SHIFTING RULE (ads + persuasive copy)
Every ad must shift at least one belief:
"Can't afford it" → "Can't afford NOT to"
"Won't work for me" → show someone exactly like them
"No time" → "Takes less time than what you're doing now"

## LANGUAGE RULE
Bulgarian by default. English if user writes in English. Never mix.
